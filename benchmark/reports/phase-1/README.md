# Phase 1 report set

Phase 1 evaluated Codex, Claude Code, and OpenCode as coding assistants; top
accessible OpenAI and Anthropic models; selected hosted open-weight models; and
two forms of multi-assistant delivery. Pi appeared as a neutral shared-model
runner in the early pilot, but it was not ranked as a fourth primary assistant.

Choose the version that matches the audience:

- [Comprehensive report](PHASE-1-COMPREHENSIVE.md) — methodology, chronology,
  complete findings, cost treatment, limitations, evidence map, and Phase 2
  boundary.
- [Executive report](PHASE-1-EXECUTIVE.md) — the decision-oriented version for
  technical leaders and stakeholders.
- [Brief](PHASE-1-BRIEF.md) — a one-page summary for quick circulation.

The three versions use the same conclusions. They intentionally preserve raw
failures, corrected-grader labels, one-run limitations, and the distinction
between metered API charges and subscription telemetry.

The larger neutral Pi model comparison is Phase 2. It has not been run as part
of these documents.
